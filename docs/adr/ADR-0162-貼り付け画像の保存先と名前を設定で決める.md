# ADR-0162-貼り付け画像の保存先と名前を設定で決める

- 状態: 採用
- 日付: 2026-11-10

## 決定

- 貼り付け・ドロップした画像の保存先フォルダーとファイル名を、エディター設定（`imageFolder`、`imageName`）で決める。既定は従来どおり `images` と `{name}`。
- 保存先は文書のフォルダーからの相対パス。`/` で始めるとワークスペース直下から数え、挿入するリンクは文書からの相対パス（`../assets/x.png` など）にする。`.` や空なら文書と同じフォルダー。
- 名前のパターンは `{name}`（元の名前）、`{date}`（`YYYY-MM-DD`）、`{time}`（`HHmmss`）を展開する。元の拡張子を必ず付け、ファイル名に使えない文字は `-` にする。展開はローカル時刻を持つ GUI 側の domain（`imageFileName`）で行う。
- 同名のファイルがあるときは失敗させず、Rust が `-1`、`-2` … を付ける。クリップボードの画像はいつも同じ名前（`image.png`）で届くため、従来は 2 枚目の貼り付けが失敗していた。
- 保存先の検証は Rust が持つ。フォルダーは 1 階層ずつ封じ込め（`..`、リンク、ワークスペース外）を確認してから作る。

## 確認方法

- `npx vitest run src/domain/image-name.test.ts`。
- `cargo test --features dev-tools --test workspace image_paste_uses_configured_folder_and_numbers_duplicates`（入れ子フォルダー、連番、`.`、`/assets`、`../..` の拒否）。
- `cargo test --features dev-tools --test explorer`（外部画像の再ドロップが `drop-1.png` になる）。
- 実アプリでの貼り付け・ドロップ、macOS / Linux は未確認。
