# ライブ表示のブラウザ検証で初回コンパイルの時間を確保する

- 状態: 採用
- 日付: 2026-10-09
- 関連 Issue: #9

## 背景

ライブ表示の Playwright harness は Vite の開発サーバーでローカルの Markdown 描画器を読み込む。空の専用キャッシュでは初回のページ読み込みにコンパイルが含まれる。Windows の手動 CI で、最初のテストは 45.0 秒、同じ検証の次回実行は 1.4 秒で成功した。既定の 30 秒では、機能の assertion に達する前に終了する。

## 決定と理由

ライブ表示のテスト全体の制限時間を 90 秒とする。assertion の既定 5 秒と retry なしの方針は維持する。製品ビルドを用いる E2E の制限時間は変更しない。

事前コンパイル専用の起動処理やテストの自動再試行は追加せず、初回読み込みを含む実際のテストを実行する。

## 結果・制約と確認方法

空の `MARXEN_VITE_LIVE_CACHE` を指定した実行と全ライブテストで確認する。読み込み後の機能不良は通常の assertion で失敗する。ブラウザでの成功を、各 OS の実 WebView や IME の確認に代用しない。
