# AI 候補の表示とチャット幅を接続状態から分離する

- 状態: 採用
- 日付: 2026-10-13
- 関連: Issue #68

## 背景

接続確認とモデル選択を同じ操作に見せると、候補を探すだけで接続したと誤認しやすい。候補の非表示が接続先やモデルを変更することも、利用者の意図と異なる。チャット幅は編集設定や AI の通信設定ではなく、画面の設定である。

## 検討した選択肢

接続プロフィールに表示設定を混在させる方法、EditorPreferences に追加する方法、独立した AI 表示設定に分ける方法を検討した。接続プロフィールと編集設定に混在させると責務と変更範囲が広がるため、独立した設定を採用する。

## 決定と理由

専用の副作用を持たない契約、正規化規則、application 所有の保存 port、localStorage adapter を用意し、composition から注入する。保存するのはプロバイダー別の候補の非表示、実際の option ID と value によるモデルの非表示、チャットの選択欄の表示、右チャットの希望幅である。認証情報、接続成功の状態、文書やネイティブの選択状態を含めない。

モデルの候補は明示的な接続確認で取得した公開値だけを使い、取得できない場合は未取得と公開なしを区別する。選択操作は再接続を行わない。非表示の現在値は選択欄に保持し、表示管理への入口を提供する。直接 API のモデル名は引き続き手入力できる。モデルの公開一覧は起動中の実測情報として保持し、固定一覧として保存しない。

右チャットはドラッグと左右キー、Home / End、リセットで操作できる。希望幅の保存範囲は 280–720px、初期値は 360px とする。固定の活動バーとサイドバーを差し引いた使用可能幅に合わせて表示だけを制限し、広げたときに元の希望幅を復元する。狭い画面では右側に重ねて表示し、既存のサイドバーに隠れないようにする。表示を閉じても会話はマウントしたまま保持する。

## 結果と制約

表示設定がネイティブの接続や実 Neovim の正本に影響しない。候補が空でも代替モデルを推測しない。保存に失敗した設定は起動中だけ保持し、管理画面に失敗を表示する。英語と標準日本語を追加し、地域表現は既存の保守的なフォールバックを使う。

## 確認方法

永続化の往復、隠した現在値の保持、未取得と公開なし、接続と選択の独立性、検索とキー操作、ドラッグと幅の制限を対象テストで確認する。テーマと狭い画面の描画はブラウザで確認し、各 OS の実 WebView / IME は別の確認対象とする。
