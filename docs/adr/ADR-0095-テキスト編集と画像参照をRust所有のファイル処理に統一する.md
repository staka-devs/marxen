# ADR-0095: テキスト編集と画像参照を Rust 所有のファイル処理に統一する

- 状態: 採用
- 日付: 2026-10-09
- 関連 Issue: #12

## 背景と選択肢

フォルダーツリーから Markdown 以外のテキストを編集し、画像を閲覧・参照できる必要がある。ブラウザーでファイルを直接読み書きする案と、既存の Neovim 文書および Rust の保存経路を拡張する案を比較した。

## 決定と理由

フォルダー、Markdown、指定されたテキスト系拡張子・設定ファイル名、および PNG/JPEG/GIF/WebP のみを表示する。Rust が UTF-8 と制御文字、画像の拡張子とシグネチャを検査し、未対応・不正なバイナリを除外する。通常テキストも実 Neovim の正本と revision 付き UTF-16 編集、Undo、原子的保存、復旧を共有し、Markdown 描画は使わない。

開いたワークスペースはフォルダーアイコンとフォルダー名で表示し、完全なパスはツールチップに置く。

画像は Neovim 文書を作らず閲覧タブで開き、フィット、等倍、25–400% の拡大縮小を提供する。ワークスペース内の画像ドラッグはコピーせず、対象 Markdown からの相対参照を URL エンコードして挿入する。DOM の内部ドラッグと Tauri の外部ファイルドロップを受ける。Windows ではネイティブドロップが HTML5 ドラッグを抑制するため、内部画像には DOM ポインタードラッグも提供する。外部画像は Rust が文書隣接の images フォルダーへ取り込む。ドロップ位置はエディタの UTF-16 座標を使い、IME の変換中は挿入しない。

## 結果と制約

画像ビューアーは Rust が検査した画像から一時的な Blob URL を作る。CSP の画像ソースに `blob:` を許可し、タブを閉じると URL を解放する。外部への通信許可は追加しない。

画像は一枚 20 MiB 以下、UI の一回のドロップは最大16枚とする。外部ファイルは読み込み前のサイズ確認と上限付き読込で制限し、保存先はワークスペース内に封じ込める。既存画像への上書き、親パスやリンク経由の逸脱、不正な範囲、古い revision を拒否する。同名の取り込みは失敗を表示し、既存ファイルを保持する。ファイル識別は拡張子とシグネチャによるもので、画像デコードの成否は閲覧時にも確認する。

## 確認方法

実 Neovim を使用する Rust テストでテキストの編集・Vim 保存・Undo・復旧、相対参照、UTF-16/revision 検査、サイズ上限、リンク経由の逸脱と取り込みを確認する。UI テストで表示対象、アイコン、選択行、画像タブ、内部ドロップを確認する。OS ごとの実 WebView の外部ドロップと IME の確認は別に行い、UI テストの成功から推定しない。
