# エディタ内にWYSIWYGのライブ描画を置く

- 状態: 採用
- 日付: 2026-10-08
- 関連 Issue: #6（描画 0060-0069 予約の 0061）

## 背景・選択肢

ライブには原文エディタと閲覧の二段表示と、編集中の文書内を直接描画する方法がある。二段表示はカーソル位置と表示が離れ、原文と見た目の対応が取れない。CodeMirror の置換装飾で原文を隠す方法は、文書位置が原文のまま保たれる。

## 決定と理由

- `src/components/editor/livePreview.ts` の StateField が共有 AST の行範囲（`src/lib/render/blocks.ts`、UTF-16 オフセット）を置換装飾にする。選択のあるブロックだけ原文表示し、他は部品として描画する。カーソルと編集位置は原文のままである。
- 部品の見た目は `renderMarkdownDocument` の HTML を部品文字列で緩衝し、参照定義を描画専用で足す。検査箱は直接切替え、表のます目の操作は対応する原文範囲を選択し、リンクや画像や脚注の操作は対応する原文位置へカーソルを移す。部品内に文字入力欄を置かず、すべての文字編集は原文の範囲編集に流す。全体の再直列化をしない。
- 部品の同一性は文字列と位置の両方で見る。前に挿入があって同じ文字列の部品が移動したときは DOM を作り直さず、結び（範囲・原文・後始末）だけ付け替える。操作の受け手は部品単位で委譲し、事象時に結びを読むので古い偏移は残らない。水和の中断器は部品の DOM に置き、作り直しと破棄で止める。
- 脚注定義は部品にせず常に原文編集とする。`livePreview` は既定で無効とし、根の表示だけが live を有効にする（source / split は無効のまま）。
- IME 確定は一回だけ送り、未確定文は送らない。外部 cursor の反響は shell 所有の連番（`seq`）で受け、座標が変われば改訂が同じでも適用する。既存 GUI 呼び出しは変えない。

## 結果・制約・確認方法

- Vitest（`blocks.test.ts`）で範囲と表ます目の対応、Playwright（開発専用 harness）で部品の配置・原文の復帰・範囲編集の保存・挿入前後の重複部品の偏移・移動水和の破棄を検証する。
- 未実施として残す。各 OS の実 WebView での部品表示、表ます目の IME 確定中の振る舞いの実機確認。
