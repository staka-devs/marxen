# ADR-0170-チャットをエージェント型にし添付を入力欄に置く

- 状態: 採用
- 日付: 2026-11-20

## 決定

- チャットの送信対象（添付した文書）のチップは、パネル上部の独立した行ではなく、入力欄の中の上側に置く。送信対象がないときの説明と「現在の選択を送る」も同じ場所に出す。
- ACP の既定モード（`workspace`）の表示名を「文書編集」から「エージェント」に改める。エージェントは作業コピーを直接編集し、終わると変更を編集中の文書へ反映して保存する（ADR-0167）。結果はエディター上部の「AI が変更しました」バー（保持・元に戻す）だけで伝え、チャットの完了サマリーと通知トーストは重ねて出さない。失敗や一部未適用のときは従来どおりチャットに出す。
- ツールカードは、実行中は開き、終わったものはタイトルの 1 行に畳む（押すと開く）。エージェントの作業コピーの場所（`marxen-staging/copy_…`）はタイトル・対象・出力・許可カードから取り除き、ファイル名だけを見せる。
- ようこそ画面の説明文を外し、「フォルダーを開いてください」はフォルダーが一つも開いていないときだけ出す。文書がないときに「コピー形式を選択」を出さない。
- 接続先・モデル・推論強度は 1 つのボタンにまとめる。表示は接続先のアイコンと「モデル名 (推論強度)」で、入力欄の幅が足りないときはアイコンだけにして行を折り返さない。押すとパネルを開き、接続先をタブ（インストール済みの ACP と登録済みの API 接続）、モデルを一覧（OpenAI・Anthropic・Google・DeepSeek・Qwen・Kimi・GLM・MiniMax・Grok・Mistral・Llama・MiMo・Nemotron はそれぞれのロゴ、ほかは汎用アイコン。ロゴは models.dev（リポジトリは MIT）の SVG の path をアプリに同梱し、実行時に外部から取得しない）、推論強度を切り替えボタンで選ぶ。パネルを開いたときにモデル候補が未取得なら取得する。再取得と表示設定はパネルの下端に置く。
- 新規ファイルは、名前が `.md` / `.markdown` で終わらなければ `.md` を付けて作る（`.xxx` は `.xxx.md`）。設定「Markdown の拡張子を付ける前に確認する」を有効にすると、付けるか・入力した名前で作るか・取り消すかを確認する。既定は確認せずに付ける。

## 確認方法

- `npx vitest run src/presentation/ai-model-controls.test.tsx src/domain/markdown-name.test.ts src/presentation/shell/hooks/useWorkspace.workbench.test.tsx`。
- `npx vitest run src/presentation/ai/agent-cards.test.tsx src/presentation/shell/WorkspaceShell.ai-review.test.tsx src/presentation/ai-panel.test.tsx`。
- Windows のリリースビルド（識別子を分けた検証用）で OpenCode に「牛乳の次の行に卵を追加」と依頼し、編集中の文書に反映され、エディター上部に保持・元に戻すが出ることを確認済み。
- Codex は既定モデルが ChatGPT アカウントで使えない旨のエラーで編集に至らなかった（エージェント側の設定）。macOS / Linux は未確認。
