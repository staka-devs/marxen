# コードの強調表示色をアプリのテーマで指定する

- 状態: 採用
- 日付: 2026-10-08
- 関連: Issue #6

Shiki は明暗双方の CSS 変数を出力し、既定色のインライン指定を無効にする。アプリのテーマに応じて CSS が背景と各トークンの文字色を指定する。コントラストテーマでは白背景と黒文字を使用する。

インラインの既定色を強制上書きする方式より、テーマを切り替えた時の色指定を一箇所に保てる。原文と編集範囲には影響しない。

確認方法はライブ描画内のコード背景とトークンの実計算色を明・暗・コントラストの各テーマで比較し、原文と編集件数が変わらないことを確認する。実 WebView の結果は検証報告に分けて記載する。
