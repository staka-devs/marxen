# 描画の隔離と水和の寿命を正す

- 状態: 採用
- 日付: 2026-10-08
- 関連 Issue: #6（描画 0060-0069 予約の 0062）

## 背景・選択肢

利用者 HTML の id / name が窓や文書の持ち物を隠す方法と、接頭辞で避ける方法がある。断片連結子の書換えを止める方法と、接頭辞先へ付け替える方法がある。数式や図の出力連結子を信じる方法と、消毒後に検査する方法がある。非同期の水和を放置する方法と、中断と破棄を結ぶ方法がある。

## 決定と理由

- すべての id / name に `marxen-` を付け、利用者 HTML が窓や文書の持ち物を隠せないようにする。本文内の `#断片` 連結子は接頭辞先へ付け替え、脚注と利用者の錨の往復を保つ。
- `href` の `data:`・`vbscript:`・`javascript:` 実行を拒む。画像 `src` の `data:` だけ残し（静止画の文脈では実行されない、貼付画像に要る）、詳説・表・kdb などの有用な HTML は残す。MathJax 出力の実行連結子は消毒後に除く。Mermaid の SVG は DOM 検査で script・事象属性・実行連結子を除いてから貼る（Mermaid strict と併用）。
- 数式の波括弧対応は MathJax 前に検査し、不正は原文と可視誤りで残す。代理対の前後境界は編集範囲に含め、絵文字の回帰で検証する。
- 水和は AbortSignal を受け、中断後の DOM 書込みをしない。地図は `remove`、Three.js は描画器・形状・材質を破棄し文脈を失わせる。古い描画と古い水和は捨てる。閲覧と部品の破棄時に必ず呼ぶ。

## 結果・制約・確認方法

- Vitest（消毒・断片・実行連結子・SVG 検査・代理対・中断解決） と Playwright（部品内の悪性 id・脚注跳躍・古い結果の破棄）で検証する。
- 未実施として残す。各 OS の実 WebView での消毒と水和の確認、署名後の配布物での外部取得の有無の再確認。
