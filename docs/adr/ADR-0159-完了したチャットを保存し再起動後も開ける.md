# ADR-0159-完了したチャットを保存し再起動後も開ける

- 状態: 採用
- 日付: 2026-10-22
- 関連 Issue: #128
- 置換元: ADR-0114 の「履歴の保持期間はアプリの起動中と表示する」

## 決定

- 完了・失敗・取消のターンを含む会話を端末内（WebView の localStorage）に保存し、起動時に履歴へ読み込む。起動時は新しい空の会話が開いた状態で始まる。
- 保存するのは本文・モード・ツール進捗・計画・到着順の段だけ。送信した文書の抜粋（contexts）、提案、送信範囲、権限の選択、フォルダーの識別子は保存しない（文書本文を含む、またはその起動中だけ有効なため）。資格情報はもともと会話に含まれない。
- 新しい順に最大50件、合計約2MBまで。超えた分は古い会話から捨てる。生成中は保存せず、ターンが終わってから保存する。
- 履歴の各行から削除でき、「すべて削除」もできる。開いている会話を削除すると新しい会話に切り替える。
- 読み込みでは形の崩れた項目を捨て、パネルは失敗させない。

## 結果・制約

- 復元した会話の「再試行」は、送信範囲を保存しないため利用できない場合がある。続けて質問することはできる。

## 確認方法

- `npx vitest run src/domain/conversation/chat-history.test.ts src/presentation/ai-panel.test.tsx`（保存対象の選別と上限、JSON の往復と不正項目、保存・再起動後の表示・削除）。
