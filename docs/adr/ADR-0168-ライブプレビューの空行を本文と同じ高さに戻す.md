# ADR-0168-ライブプレビューの空行を本文と同じ高さに戻す

- 状態: 採用
- 日付: 2026-11-10
- 置換元: ADR-0105 の「非選択のブロック間の空行だけを小さく表示する」部分

## 決定

- ライブプレビューの空行は、カーソルの有無にかかわらず本文と同じ行の高さで表示する。空行を 12px に詰める表示と、それに合わせて行番号を小さくする表示をやめる。
- 空行の高さがカーソル位置で変わると、行の間隔と行番号の並びが不揃いに見え、行番号が隣の行と重なっていた。Vim の行番号と見た目の行が常に一対一で並ぶことを優先する。
- 描画ブロック同士の余白は、ブロック自身の余白で整える。

## 確認方法

- `npx vitest run src/presentation/editor/liveTypography.test.tsx`（空行に縮小用のクラスが付かない）。
- `npm run test:e2e`（リストと表の間隔が詰まったままであること）。
- Windows のリリースビルドで、空行と行番号の並びを目視で確認する。
