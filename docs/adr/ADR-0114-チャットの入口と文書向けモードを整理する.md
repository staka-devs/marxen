# チャットの入口と文書向けモードを整理する

モードの補足説明の表示は [ADR-0130](ADR-0130-全画面の補足説明を操作に必要な情報に絞る.md) で一部置換する。

## 状況

Markdown 編集中に接続先やモデルを選び、過去の依頼へ戻れる必要がある。左側の文書ナビゲーションとチャットの入口が混在し、会話番号だけでは履歴を識別しづらかった。

## 決定

- チャットは上部右のボタンと Ctrl/Cmd+Alt+I から右サイドバーで開く。非表示でも所有している実行と変更レビューを保持する。
- 入力欄のそばに接続先、公開されたモデル候補、推論強度、モードを置く。候補は接続先の実際の応答に従い、接続設定はヘッダーのダイアログから編集する。
- モード名を「相談」「執筆」「推敲」「文書編集」とし、既存の要求種別と変更確認の規則を維持する。文書編集の変更も差分確認後に適用する。
- 選択メニューはテーマに従い、選択の説明を表示し、矢印・Enter・Escape・Tab で操作できるようにする。
- 履歴は最初の依頼をタイトルにして更新日時と現在のチャットを表示し、検索可能にする。選択した会話の接続先を復元する。履歴の保持期間はアプリの起動中と表示する。

## 検証

履歴への復帰、接続先・モデル・推論強度の変更、候補取得の遅延結果遮断、取消と変更レビュー、メニューのキーボード操作を検証する。ネイティブ接続の可否は画面の表示成功と区別する。
