# ADR-0150-版上げを一つのスクリプトで行う

- 状態: 採用
- 日付: 2026-10-21
- 関連 Issue: #116
- 置換元: なし

## 背景

版数が `package.json`、`package-lock.json`（2箇所）、`src-tauri/Cargo.toml`、`src-tauri/tauri.conf.json`、`src-tauri/Cargo.lock` の6箇所に分散し、手編集で版上げしていた。

## 検討した選択肢

1. Tauri 設定の版を `package.json` から参照させる。`assertVersionConsistency` の6箇所一致の前提が変わるため見送り。
2. 6箇所を書き換えるスクリプトを1本置く（採用）。

## 決定と理由

- `npm run version:bump -- X.Y.Z` で6箇所を行単位で置換する。JSON を再出力せず、手整形された `tauri.conf.json` などの体裁を保つ。
- 書き換え前に全ファイルの置換結果を計算し、1箇所でも見つからなければどれも書き換えない。書き込み後に `assertVersionConsistency` で一致を検証する。
- 版は `vX.Y.Z` のタグ規則（`parseTag`）に合う値だけを受け付ける。

## 確認方法

- `node --test scripts/bump-version.test.mjs`（6箇所の更新、同じ版での無変化、不正な版で無書き込み）。
