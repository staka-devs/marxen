# ADR-0091: 隔離コピーの相対パスは OS 共通の入力規則で検証する

- 状態: 採用
- 日付: 2026-10-08
- 関連 Issue: #8 / #9

## 背景と選択肢

AI の隔離コピーで扱うファイル名はワークスペース内の相対パスである。OS 標準の Path 分解だけでは、Unix で Windows のドライブ指定やルート指定を通常のファイル名として扱う。

## 決定と理由

Rust の隔離コピーへのパス検証と独立した mock CLI は、実行 OS にかかわらず Windows のドライブ指定（`C:/...`、`C:\...`、`C:...`）と先頭のバックスラッシュを拒否する。通常の絶対パス、親ディレクトリによる脱出、空パスの検査も行う。日本語・絵文字を含む相対パスと、コピー内に収まる正規化は許容する。

## 結果・制約と確認方法

OS を変えても同じ相対パス契約で判定する。実体の symlink 検査と登録範囲の照合は別途行う。Rust 回帰で Unix / Windows 形式の不正入力と有効な相対パスを確認し、各 OS の native CI で実行する。
