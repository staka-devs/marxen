# ADR-0164-編集中ブロックのインライン記法を装飾し記号を隠す

- 状態: 採用
- 日付: 2026-11-10

## 決定

- ライブプレビューで、カーソルのあるブロック（生の Markdown のまま編集するブロック）でも、太字・斜体・取り消し線・インラインコード・リンクを装飾して表示する。
- 記号（`**`、`*`、`~~`、バッククォート、`[`、`](url)`）は、選択範囲がその記法の範囲に触れていないときだけ隠す。触れているときは薄い色で見せる。Vim のモーションが隠れた文字に止まっても、その記法は開いて見える。
- 隠すのは CodeMirror の表示だけで、本文の文字と位置は変えない。Neovim のバッファと GUI の UTF-16 位置は一対一のまま。
- コード・数式・HTML のブロックには適用しない。裸の URL は装飾だけ行う。
- 記法の範囲は remark の位置情報から求める（`inlineMarks`）。
- リスト・引用のブロックでは、カーソルのない行の行頭記号を描き替える。`- ` は点、`1. ` は番号、`- [ ] ` はクリックできるチェックボックス（GUI 範囲編集で切り替える）、`> ` は左の縦線にする。カーソルのある行は生の Markdown のまま（`lineMarkers`）。
