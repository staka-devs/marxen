# ADR-0174-スラッシュメニューとブロックハンドルとボード表示でブロックを編集する

- 状態: 採用
- 日付: 2026-11-23
- 関連: ADR-0163、ADR-0166（データベース表示の有効化）

## 背景

バンドルノート（ADR-0166）はファイルのまとめ方であり、Notion のようなブロック単位の編集体験は提供していなかった。

## 決定

- **スラッシュメニュー**: Insert モードで行頭（字下げの後）に `/` を入力するとブロックの一覧を出す。続けて入力した文字で絞り込み、↑↓ で選び、Enter / Tab で挿入、Esc で閉じる。見出し、リスト、ToDo、引用、コールアウト（`> [!NOTE]`）、トグル（`<details>`）、区切り線、コード、数式、表、Mermaid、データベース（表 / ボード）を出す。
  - 開いている間の ↑↓ / Enter / Tab / Esc はメニューが受け取り、Vim には送らない。それ以外のキーは通常どおり本文に入る。
  - `/` を新しく入力したときだけ開く。スナップショットの同期やカーソル移動では開かない。
- **ブロックハンドル**: ライブプレビューでブロックにポインターを載せると、左に `+` とグリップを出す。`+` は下にブロックを挿入する。グリップはドラッグでブロックを移動し、クリックで「上へ移動・下へ移動・複製・削除」を出す。
  - 移動はブロックの本文だけを入れ替え、ブロック間の空行の位置は保つ（`moveBlockEdit`）。
  - frontmatter はハンドルの対象にしない。
- すべての操作は CodeMirror のトランザクションとして送り、通常の入力と同じ revision 付きの GUI 範囲編集で Neovim に届く。
- **ボード表示**: database ブロックに `view: board` を書くと、`group:`（既定 `status`）の値ごとの列にカードを並べる。カードを別の列へドラッグすると、その行の `group` の値を書き換える。値のない行は「未設定」列に出す。
- データベースを挿入すると、ノートの frontmatter に `database: true` を自動で書き込む。設定「データベース表示を有効にする」の既定をオンにする。保存済みの設定はそのまま。

## 確認方法

- `npx vitest run src/domain/block-edits.test.ts src/domain/database-block.test.ts src/presentation/database/hydrate-databases.test.ts`。
- `tests/live/harness/editor.html` で `/kan` → Enter によるボードの挿入と `database: true` の追加、グリップのクリックによる「下へ移動」、ドラッグによる移動を確認した。
- 実 Neovim、実アプリでのボードのドラッグ、IME 入力中の `/` は未確認。
