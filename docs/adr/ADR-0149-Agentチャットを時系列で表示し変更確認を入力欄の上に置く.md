# ADR-0149-Agentチャットを時系列で表示し変更確認を入力欄の上に置く

- 状態: 採用
- 日付: 2026-10-21
- 関連 Issue: なし（利用者要望「現代の AI Agent の挙動ではない」）
- 置換元: ADR-0114 の既定モード、ADR-0118 のカード配置の一部

## 背景

チャットは計画・ツール・権限・本文を種類ごとにまとめて表示し、実際の作業順が読めなかった。Enter で送信できず、既定は読み取り専用の「相談」で、編集させるにはモード変更が必要だった。変更の確認はチャットの下に別領域として置かれ、「差分を確認」「適用して保存」「却下」「取消」の4操作があった。

## 決定と理由

- アシスタントの1ターンを到着順の段（本文・ツール・計画・権限）として保持し、その順に表示する。本文はツールの前後で分かれる。完了時の最終本文が途中経過と異なる場合は、段の後に最終本文を置く。送信履歴には従来どおり連結した本文を使う。
- Enter で送信、Shift+Enter で改行する。IME の確定（`isComposing` / keyCode 229）では送信しない。
- ストリーミング中も末尾へ自動スクロールする。
- ACP 接続の既定モードを「文書編集」にする。変更は隔離コピーで行われ承認まで文書に入らないため安全である。HTTP 接続は回答文がそのまま取り込まれるため「相談」のままにする。
- 変更の確認を入力欄の直上に置き、変更ファイル数と「適用して保存」「破棄」の2操作にする。差分は実行完了時に自動取得されるため「差分を確認」は外し、「却下」と「取消」は「破棄」に統合する。変更がないときは適用できない。

## 結果・制約

- ストリーミング中の本文は従来どおりプレーンテキストで、完了後に Markdown 描画する（描画器は本文の変更ごとに作り直すため、途中描画はちらつく）。
- 以前に記録された段情報のない会話は従来の並びで表示する。
