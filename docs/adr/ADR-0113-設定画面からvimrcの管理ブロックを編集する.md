# ADR-0113: 設定画面からvimrcの管理ブロックを編集する

- 状態: 採用
- 日付: 2026-10-11
- 関連 Issue: #55

## 背景と選択肢

.vimrc を設定画面から調整したい。Vim 言語全体の構文解析は行わず、管理ブロック外の任意の Vimscript を保持する方式とする。全文の再生成や利用者全体設定への書込は行わない。

## 決定と理由

設定画面の Vim 分野に詳細編集を追加し、タブ幅・インデント幅・スペース・検索の大文字小文字・リーダー・モード別マッピング・複写形式キーを管理ブロックに集約する。管理ブロックは開始と終了の標識で囲み、標識の重複や不足や未知の行は拒否し、繰返しの編集で重複しない。init.lua は原文編集のみとし、管理 Vimscript を挿入しない。保存は指紋で外部変更と競合し、文書の未保存本文は保持する。空の選択はアプリ標準設定に書込み、利用者全体設定には触れない。

## 結果・制約と確認方法

Rust が読込と書込の副作用を所有し、文書や AI の経路には触れない。適用は既存の再起動経路を使い、構文と保存の誤りは画面に表示する。管理設定の純粋試験、画面試験、仮装具の保存試験、型検査と構造検査で確認する。実 WebView と IME の確認は未実施と区別する。

## Root への配線指示

合成根は `vimSettingsGateway` を作り、殻は `SettingsPanel` の `vimSettings` に `VimSettingsHost` を渡す。`VimSettingsPanel.tsx` 頭部の例をそのまま使う。保存後の適用は既存の `applyConfig` を使い、`onSaved` で選択路を設定する。主契約の再生成は行わず、別契約 `vim-settings.ts` を `export-vim-settings-contracts` で作る。
