# ADR-0143-入力中の置換コマンドを検索パネルに映す

- 状態: 採用
- 日付: 2026-10-21
- 関連 Issue: #119
- 置換元: なし（ADR-0141 の検索パネル連携を拡張）

## 背景

`/` 検索はできるのに `:s/test/a` が pattern not found になる、また `:s` の入力が GUI の検索・置換欄に反映されない、という報告があった。GUI 検索は既定で大文字小文字を区別せずリテラル一致する一方、`:s` は Vim 正規表現で大文字小文字を区別し、範囲を省略すると現在行だけを対象にする。結果として、GUI で見えている一致と `:s` の対象が食い違っていた。

## 検討した選択肢

1. 範囲なしの `:s` を全体置換に読み替える。Vim の意味論を壊すため不採用。
2. 入力中の `:s/pat/rep` を解析し、検索欄・置換欄へ映して件数を見せる（採用）。実行は従来通り実 Neovim が行う。

## 決定と理由

- `domain/search.ts` の `parseSubstituteCommand` が、範囲（`%`、`'<,'>`、行番号等）と `:s`〜`:substitute` の省略形、任意の区切り文字と区切りのエスケープを解釈する。空パターン（直前の検索）と他のコマンドは対象外。
- 解析できたら検索パネルを開き、検索語・置換語を入れ、オプションを「Vim 正規表現・大文字小文字を区別」に合わせる。これにより GUI の件数が `:s` と同じ規則で数えられる。
- パネルからの置換はワークスペース全体が対象である。現在行・範囲だけを置換したい場合は Enter で `:s` を実行する。

## 結果・制約

- Enter 前に一致件数とファイルが見え、パネルの「すべて置換」でも置換できる。
- 範囲なしの `:s` で現在行に一致がない場合の E486 は Vim の仕様どおり表示される。

## 確認方法

- `npx vitest run src/domain/search.test.ts`（範囲・省略形・区切り・エスケープ・非対象コマンド）。
- 実デスクトップでの入力中の反映の目視は未実施。
