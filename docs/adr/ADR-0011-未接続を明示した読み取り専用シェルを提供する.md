# 未接続を明示した読み取り専用シェルを提供する

- 状態: 採用
- 日付: 2026-10-07
- 関連: Issue #2、coordinator 管理 ADR-0001

## 背景と選択肢

ローカル state で編集 / Vim を模擬する案、空画面、明示した読み取り専用サンプルを検討した。模擬操作は正本の要件を誤認させ、空画面では UI 基盤を確認できない。

## 決定と理由

日本語シェルは Rust の get_runtime_status による実際の状態を表示する。ブラウザは desktop 未接続を明示し、IPC 失敗を成功に置き換えない。編集・保存・Vim mode は actor 実装まで提供しない。CodeMirror は sample のみに使用し、readOnly / editable=false とする。Tailwind CSS variables、shadcn/ui 形式の Button / Card、Radix Slot / cva を採用し、後続 UI が再利用できるようにする。

## 結果と制約

起動と表示基盤を確認できるが編集アプリとして未完成。sample は document snapshot ではない。IME / Vim は統合後の実機確認が必要。

## 確認方法

Vitest で未接続と IPC エラー、実 Chromium の Playwright で日本語、Unicode、入力による非変更、開閉、狭い画面を確認する。native WebView の成功は推定しない。
