# ADR-0157-ファイル内検索を検索バーで行う

- 状態: 採用
- 日付: 2026-10-22
- 関連 Issue: #125
- 置換元: なし

## 背景

検索・置換パネルはワークスペース全体が対象で、置換は他のファイルにも及ぶ。現在のファイルだけを検索・置換したい。

## 検討した選択肢

1. CodeMirror の検索パネルを使う。一致が JavaScript の正規表現になり、ワークスペース検索・`:s`（実 Neovim）と意味がずれるため不採用。
2. 既存のワークスペース検索フックを現在のファイルに限って使う（採用）。一致は実 Neovim、置換は改訂付きの範囲編集のまま。

## 決定と理由

- エディター右上に検索バー（VS Code の検索ウィジェット相当）を出す。件数と現在位置、Enter / Shift+Enter で前後の一致へ移動、大文字小文字・単語単位・正規表現の切替、置換行（1件置換・すべて置換）、Esc で閉じてエディターへ戻る。
- 対象は現在の文書だけ。検索は所属ルートで行い、その文書の一致だけを残す（大きなルートで遅くなる場合は文書単位のネイティブ検索を追加する）。閉じている間は検索しない。
- 「編集 > ファイル内を検索」と Ctrl/Cmd+F で開く。エディター内の Ctrl+F は Ctrl+S・Ctrl+P と同じく vimrc 優先の既定ショートカットとして割り当てる。Vim の `<C-f>`（1画面下）を使う場合は vimrc で `<C-f>` を定義するか `g:marxen_default_shortcuts = 0` にする。

## 確認方法

- `npx vitest run src/presentation/editor/FindBar.test.tsx`（件数・前後移動・切替・置換・Esc、文書への絞り込みと閉じている間の停止）。
- `cargo test --test vim_input`（既定ショートカットの設定）。
- 実デスクトップでの操作は未確認。
