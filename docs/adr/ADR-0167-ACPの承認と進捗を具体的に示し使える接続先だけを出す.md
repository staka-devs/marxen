# ADR-0167-ACPの承認と進捗を具体的に示し使える接続先だけを出す

- 状態: 採用
- 日付: 2026-11-10

## 決定

- 許可の要求（`session/request_permission`）は、ツールの種類（コマンド実行、ネットワーク取得、削除など）、`rawInput` のコマンド・パス・URL・検索語、変更の差分、対象ファイルを添えてチャットに出す。
- 読み取り・検索・思考・編集の許可は、利用者に聞かずに「今回のみ許可」で答える。編集は隔離された作業コピーへの書き込みで、文書に反映したあとも取り消せる。コマンド実行・ネットワーク取得・削除・移動などは従来どおり利用者に聞く。質問モードは従来どおりすべて拒否する。
- ツールカードは、ツールが報告した出力（末尾 12 行）と差分（変化した行だけ、12 行まで）を表示する。実行中は入力欄の上に「〇〇 を実行しています…」と現在のツールを出す。
- 文書編集モードの指示を「変更を頼まれたら作業コピーのファイルを直接編集する。質問には回答だけを返す」に改める。従来は「提案テキストのみを返し、直接書き込みません」と指示していたため、編集を頼んでもファイルに反映されなかった。変更がない応答は、失敗ではなく回答として静かに終える。
- 接続先の選択欄と AI の表示設定には、コマンドがインストールされている ACP エージェントだけを出す。判定は PATH 上の起動先の解決だけで、エージェントを起動しない。選択中の接続先は未インストールでも残す。
- 「接続を確認」はアイコンだけにし、接続中だけ文字を出す。モデル候補が未取得の説明文は出さない。

## 確認方法

- `cargo test --features dev-tools --lib permission_tests`（種類・コマンド・差分・対象の読み取り、自動許可の範囲）。
- `npx vitest run src/presentation/ai/agent-cards.test.tsx src/presentation/ai/AiVisibilitySettings.test.tsx`。
- 実際の ACP エージェントでの許可・編集の流れ、macOS / Linux は未確認。
