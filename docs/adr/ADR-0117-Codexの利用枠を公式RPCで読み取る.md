# Codex の利用枠を公式 RPC で読み取る

## 決定

コンテキストの使用率とアカウントの利用枠は別の値として表示する。Codex の利用枠は、インストール済み CLI の App Server に対する `account/rateLimits/read` で取得する。CLI が管理する既存の認証を利用し、アプリは認証ファイルやトークンを読み取らない。

取得は明示的な使用量操作で行う。初期化と利用枠の読み取りだけを許可し、スレッド・推論・ログイン・獲得したリセット権の消費は要求しない。読み取り用プロセスは期限を設け、成功・失敗のどちらでも終了を待って回収する。

## 表示する値

報告された bucket ごとに使用率、期間、リセット時刻、クレジットの状態を表示する。複数 bucket がある場合は公式の複数 bucket 表現を優先し、合算しない。期間を固定の 5 時間・1 週間と仮定しない。未報告の値は省略し、トークン数から利用枠・料金・クレジットを推計しない。

アカウント識別子・メールアドレス・認証情報は IPC に渡さない。クレジット残高は報告された十進表記を保持し、未報告の通貨や消費額を補わない。API エラーの本文も返却せず、取得の失敗だけを画面に伝える。

## 根拠

[Codex App Server の公式仕様](https://learn.chatgpt.com/docs/app-server) に、利用枠の RPC、bucket、使用率、期間、リセット時刻、クレジットの意味が定義されている。ACP のコンテキスト報告には同じアカウント情報が定義されていないため、二つの値を区別する。
