# ADR-0094: 分割表示は Markdown 編集とプレビューを左右に配置する

- 状態: 採用
- 日付: 2026-10-08
- 関連 Issue: #5 / #9

## 背景と選択肢

Markdown を編集しながら描画結果を確認できる分割表示が必要である。編集欄を二つ並べる表示と、編集欄とプレビューを並べる表示では目的が異なる。

## 決定と理由

「分割表示」は左に Markdown 編集欄、右に同じ文書のプレビューを配置する。編集・保存・Vim 操作は既存の Neovim 文書を使用し、プレビューは変更された本文を描画する。境界はドラッグと左右キーで幅を調整でき、Home キーとダブルクリックで等分に戻せる。各ペインは独立してスクロールする。

表示モード名は「ライブプレビュー」「Markdown」「プレビュー」「分割表示」とする。タブと操作ボタンは一段に集約し、同じファイル名を別の見出しへ重複表示しない。編集領域は余分なカード枠や角丸を除き、落ち着いた中立色を使用する。

操作案内とエラーでは「文書」「Markdown」「Neovim 画面」を使い、「原文」という表示名は使わない。

## 結果・制約と確認方法

製品 E2E で編集欄が一つだけ存在すること、左右の位置、プレビュー内容、境界の幅調整、モード変更後も文書を保持することを確認する。実 WebView では Vim 編集後の描画とスクロールを別途確認する。分割モードは文書を二つ開く機能ではなく、一つの文書を編集と描画の両面から表示する。
