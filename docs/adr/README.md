# AnyDR（あらゆる意思決定の記録）

アプリの実装、機能、UI、製品仕様、検証方法、配布の設計に関わる持続的な意思決定をここに残す。

## 命名と配置

- 配置先は `docs/adr/`。
- 名前は必ず `ADR-{4桁のゼロ埋め連番}-{意思決定が分かる日本語タイトル}.md`。
- 連番は既存ファイルの最大番号の次を使う。複数担当者は番号を調整する。
- AnyDR は記録範囲を表す。ユーザー指定の ADR ファイル名形式を維持する。

## 記録する内容

状態（提案 / 採用 / 保留 / 置換）、日付、関連 Issue、背景、検討した選択肢、決定と理由、結果・制約、確認方法を簡潔に記載する。過去の判断を変更するときは新しい記録を追加し、置換元と置換先をリンクする。未検証の判断はその条件を記載する。

アプリの最終的な振る舞いと、その理由が分かる記録にする。エージェントのモデル・担当変更・委任、承認待ち、実装途中の経緯、一時的な仮実装の状態は記録しない。これらを作業ログへ移して保存することもしない。

実際に実施した検証のコマンド・結果と未検証の範囲は検証報告へ記載する。開発中の出来事の時系列は含めない。
