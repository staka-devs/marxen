# ADR-0155-ライブプレビューでも行番号を表示する

- 状態: 採用
- 日付: 2026-10-22
- 関連 Issue: なし（利用者要望）
- 置換元: ADR-0105 / 編集設定の「ライブプレビューは行番号を出さない」

## 決定

- 設定「Markdown の行番号を表示する」が有効なら、ライブプレビューでも行番号を表示する。
- 表・図などの描画ブロックは1行の部品として表示されるため、その先頭行の番号を示す。

## 確認方法

- 実アプリ（開発版）のライブプレビューで行番号の列が出ることを確認。`npx vitest run src/App.ux.test.tsx`。
