# ADR-0022: Vim の保存は所有文書を Rust 経由で書き込む

- 状態: 採用
- 対象: Neovim の保存操作、文書の競合検知

## 決定

所有するバッファに限って `BufWriteCmd` を登録し、`:w` と `:w!` は Rust に保存要求を渡す。`!` で外部変更の競合検知を迂回しない。保存に成功した時点で Rust が保存基準と変更状態を更新する。

別名の書き込みはアプリの「名前を付けて保存」で扱う。部分保存と追記は `FileWriteCmd` / `FileAppendCmd` で拒否し、Neovim から文書の保存処理を迂回させない。登録はバッファ単位で冪等にする。

Neovim は Windows でコンソールを表示せず起動する。終了検出には所有プロセスの状態を使い、切断した RPC の応答を待ち続けない。

## 理由

Vim と GUI が同じ競合検知、文字コード・改行保持、原子的な保存を使うため。部分保存や追記は文書全体の保存基準と一致しないため、暗黙に通常保存へ置き換えない。

## 検証

実 Neovim で通常保存と強制保存の要求、再登録による重複防止、別名・部分保存・追記の拒否、ファイルが直接変更されないことを確認する。プロセス終了時の接続状態と待機中 RPC の解除も検証する。
