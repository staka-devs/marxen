# ADR-0156-Gitの変更を行番号の横に示す

- 状態: 採用
- 日付: 2026-10-22
- 関連 Issue: #124
- 置換元: なし（ADR-0146 のソース管理ビューを補う）

## 決定

- 編集中の文書の現在の本文（未保存の編集を含む）と Git HEAD の内容を行単位で比べ、行番号の右に追加（緑）・変更（青）・削除（赤の三角）を示す。VS Code のクイック差分に相当する。
- HEAD の内容は `git cat-file blob HEAD:./<path>` で読む。フィルターやテキスト変換を通さないため、リポジトリ設定のプログラムは実行されない。パスは ADR-0146 と同じ規則で検証し、登録済みルートからだけ解決する。4MiB を超える・UTF-8 でない・未追跡・コミットがない場合は表示しない。
- 改行は比較前に CR を除いて揃える（Windows の CRLF 作業ツリーと LF の blob で全行が変更扱いになるのを防ぐ）。
- 文書を開いたときと保存（未保存フラグの変化）で HEAD の内容を読み直す。差分は AI 差分表示と同じ行差分（`lineChanges`）で都度計算する。

## 結果・制約

- ブランチ切替やコミットは、次に文書を開くか保存するまで反映されない。
- 外部ツールで作業ツリーを変更した場合も同様。

## 確認方法

- `cargo test --test source_control`（HEAD の内容の取得、未追跡は無し、パス拒否。Windows の実 Git で実施）。
- `npx vitest run src/presentation/editor`（追加・変更・削除の印、CRLF の無視、基準なしで非表示）。
- 実デスクトップでの見た目は未確認。
