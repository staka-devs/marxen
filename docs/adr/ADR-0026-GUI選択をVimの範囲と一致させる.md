# GUI 選択を Vim の範囲と一致させる

- 状態: 採用
- 日付: 2026-10-08
- 関連 Issue: #3、#5

## 背景と選択肢

GUI の選択は半開区間であり、Neovim の Visual 選択は設定によって端点の文字を含む。カーソルだけを移すと、アンカーが残ったり選択が消えたりして、表示した範囲と Vim の操作対象が異なる。

## 決定

Normal / Visual の GUI 選択は、原文位置から実 Neovim の両端点を設定する。行選択の種類と方向を保持し、`selection=exclusive` を考慮する。改行と末尾を含む GUI 選択では、その選択が終わるまでウィンドウの `virtualedit` に `onemore` を補い、終了時に元の値を戻す。入力待ちの操作は中断せずに拒否する。

矩形選択は連続範囲として受け付けない。Insert の GUI 選択によってモードを切り替えず、GUI 範囲編集の契約を維持する。ユーザーのキーは通常どおりマッピングを通す。

## 結果と確認方法

選択報告は改行・Unicode を含む実際の Vim 削除範囲と一致し、選択移動では本文 revision や Undo 履歴を増やさない。実 Neovim で正逆の文字選択、exclusive、行選択のアンカー変更、改行・文書末尾の削除と Undo、設定の復元を確認する。
