# GitHub記法と不正な入力を共通サンプルで検証する

- 状態: 採用
- 日付: 2026-10-07
- 関連 Issue: #5, #6, #9

## 背景・選択肢

ライブプレビュー・閲覧・原文の描画をそれぞれ独立したサンプルで確認する方法と、保存された同一の Markdown fixture を共用する方法を比較した。表示の成功だけでは原文保持や失敗時の編集継続を確認できない。

## 決定と理由

`tests/fixtures/github-markdown.md` を正常系の共通サンプルとする。GFM、五種の Alerts、脚注、コード、Mermaid、数式、HTML、地図、ASCII STL、日本語と絵文字、相対画像・リンク、参照リンクを含める。不正構文と実行可能 HTML は別 fixture とし、エラー表示・編集継続・サニタイズを確認する。

## 結果・制約・確認方法

各 fixture をライブ・閲覧モードで使用し、表示確認と未編集原文の保存前後比較を行う。チェックボックスなどを編集した場合は変更範囲だけが更新されることを確認する。fixture の追加自体は機能の実装や検証成功を意味しない。各 OS の WebView・IME は別途実環境で確認する。
