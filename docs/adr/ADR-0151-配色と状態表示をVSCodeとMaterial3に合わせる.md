# ADR-0151-配色と状態表示をVSCodeとMaterial3に合わせる

- 状態: 採用
- 日付: 2026-10-21
- 関連 Issue: なし（利用者要望「VS Code にもっと寄せる。Material 3 の考え方も参考にする」）
- 置換元: ADR-0055 / ADR-0102 の配色値（構成は維持）

## 背景

画面構成（活動バー・単一側面・タブ・パンくず・状態バー）は VS Code に近いが、配色が青みがかった独自の値で、状態バーが編集列の中だけにあり、Vim のモード表示が目立たなかった。

## 決定と理由

- 配色トークンを VS Code の Light Modern / Dark Modern の中立色に合わせる（本文 #FFFFFF / #1F1F1F、側面・活動バー・状態バー #F8F8F8 / #181818、境界 #E5E5E5 / #2B2B2B）。ダークの強調色は Material 3 の tonal 配色にならい、明るい青（#4DAAFC）に暗い文字を載せてボタン文字のコントラストを保つ。
- 活動バーは側面と同じ面の色にする。
- 状態バーをウィンドウ全幅の最下部に置く（VS Code と同じ）。
- Vim のモードを状態バー左端の塗りつぶしチップで示し、ノーマル・挿入・ビジュアル・置換・コマンドで色を変える。文字色とのコントラストは各色で 4.5:1 以上。ハイコントラストは黒地白文字に固定する。
- アクティブなタブは常に閉じるボタンを表示する。
- ライブプレビューでは現在行を塗らず、左端の線だけで示す（文書として読める見た目を保つ）。原文表示は従来どおり。

## 結果・制約

- 既存のトークン（`--background` 等）の値を変えるだけで、部品の構成は変えない。
- 実デスクトップ（各 OS の WebView）での見た目は未確認。ブラウザ表示で配色・タブ・状態バーのみ目視した。

## 確認方法

- ブラウザ表示（`npm run dev`）でライト・ダークの画面を目視。
- `npx vitest run src/App src/presentation/shell src/presentation/workspace`。
