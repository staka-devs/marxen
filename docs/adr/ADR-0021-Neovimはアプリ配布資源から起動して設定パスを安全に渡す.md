# Neovim はアプリ配布資源から起動して設定パスを安全に渡す

- 状態: 採用
- 日付: 2026-10-07
- 関連 Issue: #3、#9

## 背景と選択肢

Neovim の資源配置は Windows、macOS、Linux で異なる。実行ファイルの隣を仮定する方法と、Tauri の資源ディレクトリを使う方法を比較した。ユーザー設定ファイルには空白・日本語を含むパスを使用できる必要がある。

## 決定と理由

アプリ起動時に Tauri の `resource_dir` を Rust に設定し、その配下の `neovim/` から実行ファイルと runtime を解決する。配布版は開発元の絶対パスへフォールバックしない。開発・テストでのみソースツリーの配布資源を使用する。配布情報は JSON として解析し、対象 OS / CPU を取得する。

設定ファイルの読込は Neovim の `fnameescape` を使い、ファイル名を Ex コマンドとして解釈しない。RPC クライアントの破棄時は所有する子プロセスを終了し、RPC の EOF は待機中の要求を直ちにエラーにする。stderr は読み捨てを継続しながら直近 64 KiB に制限する。

## 確認方法と制約

実 Neovim で空白・日本語パスの Vim / Lua 設定読込、終了したプロセスへの RPC、配布情報の対象識別を検証する。インストーラを使った各 OS の起動と WebView / IME は、それぞれ実施結果を確認する。
