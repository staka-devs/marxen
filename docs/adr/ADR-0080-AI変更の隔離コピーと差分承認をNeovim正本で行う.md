# AI変更の隔離コピーと差分承認をNeovim正本で行う

- 状態: 採用
- 日付: 2026-10-08
- 関連 Issue: #8、Epic #1

AI に提示する文書は隔離コピーへ置き、モデルの提案は差分レビューを経て、利用者が承認した範囲パッチだけを実 Neovim へ適用する。Rust が送信範囲、改訂、ディスクの競合、安全なパス、実行とコピーの寿命を管理する。

コピーは OS の一時領域に作り、文書 ID・改訂・範囲・抜粋を正本と照合する。選択範囲だけを配置し、絶対パスのメタデータは内部に保持する。ACP はそのコピーを作業ディレクトリとし、HTTP の提案も同じコピーへ取り込む。コピーによる隔離は OS サンドボックスではない。

差分の取得、却下、取消は正本やディスクを変更しない。承認前には全対象を検証し、適用結果は文書ごとに返す。適用時の失敗では実 Neovim の Undo で可能な限り戻し、その成否を明示する。ディスクへの保存は、承認後も共有の保存操作で行う。

送信範囲と最小編集は [ADR-0081](ADR-0081-選択範囲のみの隔離コピーと提案の取り込みをRUSTが検証する.md)、実行中の固定と承認結果は [ADR-0082](ADR-0082-実行中の隔離コピーを固定し承認結果を文書毎に報告する.md)、範囲照合と終了順序は [ADR-0083](ADR-0083-送信範囲の完全一致と実行完了後の端末配信を保証する.md) と [ADR-0084](ADR-0084-実行完了の共通処理で子の刈り取りと端末の一度配信を行う.md) に従う。

確認には実 Neovim、模擬 CLI / HTTP、遅延書き込み、失敗注入を使い、却下・取消・競合時の原文保持、単一 Undo、終了後の承認を検証する。Rust と TypeScript の契約を生成して照合する。実 CLI の認証接続とネイティブ配布物は独立に検証し、結果は検証報告に記載する。
