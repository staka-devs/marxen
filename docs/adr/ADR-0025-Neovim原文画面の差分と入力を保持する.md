# Neovim 原文画面の差分と入力を保持する

- 状態: 採用
- 日付: 2026-10-08
- 関連 Issue: #3、#5

## 背景と選択肢

プラグイン画面と矩形選択は Markdown の連続範囲だけでは表せない。行を文字列として置き換える表示では、部分再描画で他の列を失い、カーソル移動も見えなくなる。

## 決定

Neovim の RGB UI を接続し、グリッドのセル、色属性、カーソル、スクロール領域を差分から累積する。原文画面へのキー入力は実 Neovim へ送り、画面の文字列を GUI の本文へ逆変換しない。全角セルは次の空セルと合わせて表示する。

## 結果と確認方法

本文 revision が変わらない移動やプラグインの再描画も表示できる。文書切り替え時に画面状態をリセットし、表示中の再描画取得を本文の更新と独立して行う。矩形選択を連続範囲へ拡張して GUI 編集や AI 送信に利用しない。

検証では部分更新・領域スクロール・色属性の保持、全角表示、カーソルだけの移動、キーと合成文字列の一回の転送を確認する。各 OS の実 IME は別途検証する。
