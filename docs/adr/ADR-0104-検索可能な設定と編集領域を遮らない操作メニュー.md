# 検索可能な設定と編集領域を遮らない操作メニュー

状態: 採用
日付: 2026-10-10
関連 Issue: #17

## 背景

設定を探すためにカテゴリを巡回する操作と、AI 接続を別パネルで変更する操作を減らす。編集操作の一覧は文書の中央を大きく覆わず、キーボードでも選べる必要がある。

## 選択肢

設定カテゴリごとに独立した画面を用意する方法と、一つの設定画面でカテゴリ・検索を使う方法を比較した。操作一覧は中央のパネルと、起点のボタンに揃えた小さなポップオーバーを比較した。

## 決定

- 設定は初期表示で全カテゴリを並べ、検索は選択中のカテゴリにかかわらず該当項目を含むカテゴリを表示する。表示設定を即時保存し、Neovim 設定の適用は再起動の影響を説明した上で明示的なボタンを使う。
- Agent チャットと設定画面は同じ接続設定コンポーネント、provider、profile store を使う。他方で変更した provider を表示へ反映する。ACP ではエージェント自身の認証を使うため、API キー入力は HTTP API の接続時だけ表示する。
- 編集操作はタブ行の右端に揃えたポップオーバーへ配置する。書式はアイコン、コマンドは一列の名称とショートカットで表示する。矢印・Home・End で移動し、Escape・外側クリックで閉じる。
- ライブプレビューでは置換されたブロックに対応しない行番号を表示しない。行番号設定は Markdown 編集と分割表示の編集側に適用する。Vim のカーソルはモードごとに形を分け、色と輪郭で位置を示す。
- ファイルツリーはフォルダーの階層線とファイル種別のアイコンを持つ。サイドバーの幅はポインターとキーボードで変更できる。

## 制約と確認方法

検索はラベルと設定の検索語からカテゴリを絞る。個々の設定を全文検索する仕組みは追加しない。表示・サイズ変更は presentation の状態で、文書・保存・AI 通信の所有権を変更しない。

検索、即時保存、provider の同期、操作メニューの終了とフォーカス復帰、サイドバーのサイズ変更、表示モードごとの行番号をテストする。画面の密度・余白・カーソルの視認性はスクリーンショットと実 Windows WebView で別に確認する。
