# ADR-0145-ライブプレビューと閲覧の本文幅を広げる

- 状態: 採用
- 日付: 2026-10-21
- 関連 Issue: なし（利用者要望）
- 置換元: ADR-0105 の「本文は最大 760px の幅に揃え」

## 背景

ライブプレビューと閲覧表示で左右の余白が大きすぎ、本文が狭いという指摘があった。

## 決定と理由

- 本文列の最大幅を 760px から 960px に広げ、狭い画面での最小余白を 32px から 24px にする。ライブプレビューと閲覧表示で同じ値を使う。
- 原文表示は従来どおり幅制限なし。

## 確認方法

- CSS の変更のみ。実デスクトップでの見た目の確認は未実施。
