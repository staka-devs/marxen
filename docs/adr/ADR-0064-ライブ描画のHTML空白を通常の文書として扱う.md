# ライブ描画の HTML 空白を通常の文書として扱う

- 状態: 採用
- 日付: 2026-10-08
- 関連 Issue: #5、#6

## 背景と選択肢

CodeMirror は原文の改行を保存して表示する。描画した HTML にもその空白規則を継承すると、表などのマークアップ間の改行まで表示の高さに加算される。

## 決定

ライブウィジェットの HTML は `white-space: normal` にして通常の文書として描画する。原文の行とコードの整形済み表示は、それぞれの空白規則を維持する。ブロック間の間隔は文書用の余白に従い、固定高さや原文の書き換えで調整しない。

## 確認方法

リスト直後の表に過剰な空白が発生しないことを実ブラウザの位置で検証し、選択したブロックの原文、コード、特殊ブロックの描画を回帰確認する。
