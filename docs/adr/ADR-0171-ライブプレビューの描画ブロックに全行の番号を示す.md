# ADR-0171-ライブプレビューの描画ブロックに全行の番号を示す

- 状態: 採用
- 日付: 2026-11-23
- 置換元: ADR-0155 の「その先頭行の番号を示す」部分

## 決定

- 表・frontmatter・図などの描画ブロックは複数のソース行を 1 つの部品に置き換えるため、行番号の欄に番号が出ていなかった。CodeMirror の `lineNumberWidgetMarker` でブロックごとの番号を出す。
- ブロックの高さが 1 行あたりの高さ × 行数以上なら、全行の番号を縦に並べる。足りないときは先頭行と末尾行の番号を上端と下端に置き、間を細い線でつなぐ。番号が隣の行と重ならないことを優先する（ADR-0168）。
- ライブプレビューの左余白を 52px 以上にし、ブロックハンドル（ADR-0174）と行番号が重ならないようにする。

## 確認方法

- 開発サーバーの `tests/live/harness/editor.html` で、4 行の frontmatter は 1〜4 をすべて、表は先頭と末尾の番号を表示することを目視で確認した。
- 実アプリ（Windows / macOS / Linux の WebView）での見た目は未確認。
