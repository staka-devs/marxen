# Vimの選択範囲を原文の半開区間として共有する

- 状態: 採用
- 日付: 2026-10-08
- 関連 Issue: #3、#5、#8

## 背景と選択肢

Vimの文字・行選択は終端を含む場合があり、GUIとAIの範囲編集はUTF-16の半開区間を使う。カーソルだけを返す方法では選択本文を共有できず、単純な文字数加算では絵文字・結合文字・`selection=exclusive`を扱えない。

## 決定

実Neovimの`getregionpos()`と`getregion()`で選択本文と位置を取得し、Rustが原文のUTF-8座標からUTF-16の半開区間へ変換する。選択方向を保ち、行選択は存在する末尾改行を含める。GUIのカーソル更新は文書リビジョンと独立した連番で反映する。

矩形選択は単一の連続範囲に広げない。実Neovimの矩形操作を維持し、矩形を表現できないGUI・AIの選択範囲操作は無効にする。入力待ちで返すキャッシュも現在の原文長とサロゲート境界へ制限する。

複数文書への承認は、各actorの入力待ち・実バッファ・リビジョン・編集範囲を変更前に検証する。適用時にも検証し直し、事前検証後に発生した失敗は文書ごとの結果として扱う。

## 確認方法と制約

同梱Neovimで日本語・絵文字、正逆方向、排他的選択、行末改行、矩形操作とUndo、入力待ちキャッシュを確認する。GUI・AIは同じ範囲を利用し、原文の選択外を保持する。各OSのWebView・IMEは実機検証を別に行う。

座標と選択の仕様は同梱Neovim 0.11.5の`vimfn.txt`、`visual.txt`に従う。
