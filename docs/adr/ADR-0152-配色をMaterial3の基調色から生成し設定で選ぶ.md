# ADR-0152-配色をMaterial3の基調色から生成し設定で選ぶ

- 状態: 採用
- 日付: 2026-10-21
- 関連 Issue: なし（利用者要望「配色は設定で決められるように。Material 3 ベース」）
- 置換元: ADR-0151 の固定配色値（構成・状態表示の決定は維持）

## 背景

ADR-0151 で配色を VS Code Modern の固定値にしたが、利用者は配色を設定で選べ、Material 3 を基にしたいと求めた。選択肢として Material のカラーパレット（19色相・最大14の濃さ）を使いたい。

## 検討した選択肢

1. 固定のテーマを複数用意する。組み合わせが増えるほど保守が重く、コントラストの保証が個別になるため不採用。
2. Material 3 の動的配色で、1つの基調色からライト・ダークの全トークンを生成する（採用）。色計算は Google 公式の `@material/material-color-utilities` を使う（HCT 色空間の自作は避ける）。0.4.0 は ESM の import 拡張子欠落で Node から読めないため 0.3.0 に固定する。
3. tonal-spot 方式を使う。基調色の彩度を固定値に置き換えるため濃さの選択が結果にほぼ現れず不採用。fidelity 方式で基調色の彩度を保つ。

## 決定と理由

- 設定「外観」に「配色の基調色」を置き、19色相 → その色相の濃さ（50〜900、A100〜A700。ブラウン・グレー・ブルーグレーは10段）を選ぶ。任意の色も選べる。既定は Blue 700（#1976d2）。
- 濃さは主に明度の違いだが、Material 3 は役割ごとに明度を決め直して可読性を保つため、生成結果には主に鮮やかさの違いとして現れる。
- 生成した `--background` `--foreground` `--card` `--muted` `--muted-foreground` `--border` `--primary` `--primary-foreground` `--vim-normal` を、`styles.css` の後に挿入するスタイルシートで `light` / `dark` に上書きする。ポータル表示のポップアップにも同じ値が届く。ハイコントラストは固定の黒白を維持する。
- 基調色は編集設定 `seedColor`（`#rrggbb`）として保存し、不正値は既定に戻す。

## 結果・制約

- パレットの全254色について、ライト・ダークとも本文と背景 7:1 以上、補助文字と強調色上の文字 4.5:1 以上を検査で保証する。
- Vim モードの挿入・ビジュアル・置換・コマンドの色、Git 状態色は意味を持つ固定色のまま。
