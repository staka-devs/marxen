# 全画面の補足説明を操作に必要な情報に絞る

- 状態: 採用
- 日付: 2026-10-16
- 関連: Issue #100 / #17 / #20 / #53 / #60
- 一部置換: [ADR-0114](ADR-0114-チャットの入口と文書向けモードを整理する.md) のモード説明、[ADR-0122](ADR-0122-全文検索と置換の一致規則をネイティブに統一する.md) の検索画面の補足表示。

## 背景

各画面に内部仕様や操作名と重複する説明が増え、必要な項目を探しにくくなっていた。

## 決定と理由

説明を折りたたんで残す案と、不要な説明を削る案を比較し、全画面で後者を採用する。検索エンジンの構文・数値上限、起動コマンド、実装上の保持保証、応答ごとの定型補足は表示しない。設定名やボタンから分かる操作の説明も削除する。

入力形式、操作できない理由と対処、未保存データ・Undo・履歴の保持範囲、資格情報の保存先と削除対象は簡潔に示す。検索打ち切りと一括置換の制限も発生時に伝える。技術仕様は開発文書で管理し、画面から削った項目の未使用翻訳も取り除く。

## 結果と確認方法

検索・編集・保存・AI 通信の処理規則は維持する。日本語・英語と地域表現のフォールバックを揃え、既存の画面テストで操作、警告、フォーカス移動を確認する。型・翻訳・五層依存の検査を行う。各 OS の実 WebView の表示確認は別途必要とする。
