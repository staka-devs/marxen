# ADR-0169-補足説明はinfoアイコンのポップオーバーに置き自動回復は通知しない

- 状態: 採用
- 日付: 2026-11-20

## 決定

- 画面に常に出していた補足説明（資格情報の保存先、アカウント選択の適用時期、置換が使えない理由、コピー形式キーの使い方、`:Marxen` の呼び出し方、設定の画像フォルダー・ファイル名・データベースの説明）は、ⓘ アイコンを押すと開くポップオーバーに移す（`InfoHint`）。Escape、再度のクリック、外側のクリックで閉じる。説明文はボタンの説明（`aria-describedby`）として支援技術に残す。
- 状態の表示（空の一覧、取り消し、他の応答の生成中など）や、利用者の判断が必要な確認文は、補足ではないので画面に残す。
- 改訂のずれで GUI が最新の本文に再同期したときの通知（「改訂が古いため最新のMarkdownに再同期しました」）を出さない（Issue #130）。再同期は自動で完了し、利用者が対処することはないため。画面は Rust の正本の本文に戻る。

## 確認方法

- `npx vitest run src/presentation/ui/info-hint.test.tsx`（既定で非表示、押すと表示、Escape で閉じる、説明が支援技術に残る）。
- `npx vitest run src/presentation/shell/WorkspaceShell.registry.test.tsx`（古い改訂の貼り付けは何も書き込まず、通知なしで外部の変更を表示する）。
- 実アプリでのポップオーバーの見た目は未確認。
