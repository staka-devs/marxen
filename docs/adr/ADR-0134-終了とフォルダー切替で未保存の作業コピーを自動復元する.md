# ADR-0134: 終了とフォルダー切替で未保存の作業コピーを自動復元する

- 状態: 採用
- 日付: 2026-10-16
- 関連: #102、#84

## 背景と決定

VSCodeのHot Exitと同様に、終了・フォルダー切替のたびに未保存文書の判断を求めず、作業コピーを保持して再開する。自動保存でディスクの原本を変更する案は採らない。

- 文書変更ごとのRustの復元チェックポイントを継続する。フォルダーを置き換える前に全バッファを同期・チェックポイントし、失敗した場合は切替を中止する。
- フォルダーを開く際、まだ開かれていない復元文書を自動的に再登録する。パスなし文書もタブへ戻す。
- 外部変更があっても復元本文を保持し、元のディスク指紋を維持する。競合を黙って保存・上書きしない。
- 文書を明示的に閉じて変更を破棄する場合の保存・破棄・取消は、VSCode同様に残す。

## 結果・確認方法

復元失敗のチェックポイントは削除せず、エラーとして表示する。Rustの所有権・世代・復元と、画面の再起動・タブ復元をテストする。OSの強制終了直前に未確定の入力まで永続化できたと推定しない。
