# ADR-0138-阿波弁の対象を徳島県全域にする

- 状態: 採用
- 日付: 2026-10-17
- 関連 Issue: #60
- 置換元: ADR-0115（徳島市・鳴門周辺を基準）

## 背景

言語選択肢の表示が「阿波弁 (徳島・鳴門)」となっており、対象が徳島市・鳴門周辺に限定されているように読める。利用者からは徳島全域の表現として扱ってほしいとの要望がある。

## 検討した選択肢

1. 表示だけ「阿波弁」に変え、基準は徳島市・鳴門のままにする。表示と基準が食い違うため不採用。
2. 対象を徳島県全域に広げ、表示の括弧を外す。県内の地域差は訳文の絞り込みで吸収する。採用。
3. 地域ごとに細分化する（例: 北部・南部）。訳文の検証コストが見合わないため不採用。

## 決定と理由

`ja-JP-x-tokushima` の対象を徳島県全域とし、選択肢の表示を「阿波弁」にする。特定の市周辺への限定をやめ、県内の地域差がある語は地域オーバーレイに入れないことで誤用を避ける。

## 結果・制約

- 設定の言語選択肢は「阿波弁」と表示する。英語表示は `Japanese – Awa`。
- `docs/implementation.md` と `docs/localization.md` の対象記述を徳島県全域に更新する。
- 徳島の話者の確認により、地域オーバーレイの保存通知は「保存したでよ。」とする。文の追加は徳島の話者確認を必須とする。

## 確認方法

- `npm run localization:check` でキー不足がないこと。
- 設定画面で言語選択肢に「阿波弁」と表示され、括弧付きの旧表示が出ないこと。
- `npm test -- src/presentation/i18n src/infrastructure/localization` で地域フォールバックが壊れていないこと（話者レビュー自体は未実施として区別する）。
