# ADR-0160-Vimの検索とファイル内検索バーを双方向に連動させる

- 状態: 採用
- 日付: 2026-11-09
- 置換元: ADR-0143（入力中の置換コマンドを検索パネルに映す）

## 決定

- Vim のコマンドラインで入力中の `/pat`、`?pat`、`:s/pat/rep` を、ファイル内検索バー（Ctrl+F）へそのまま写す。Enter 前から一致数を表示し、エディタ上の一致を強調する（`hlsearch` 相当）。`:s` のときは置換欄も開く。
- Vim から開いたときは検索バーにフォーカスを移さない。キーボードは Vim のコマンドラインに残る。Enter 後もバーは開いたままにする。
- `:s` は現在のバッファへの操作なので、サイドバーの全体検索ではなくファイル内検索バーへ写す。
- 検索バーで利用者が入力した語と条件は、Vim の最後の検索パターン（`@/`）と検索履歴に入れる。`n` / `N` / `:s//` が同じ語を辿る。パターンは Vim のコマンドラインに表示されるため、語に応じて最小にする。リテラルは Vim の特殊文字（`\ . * [ ] ~ ^ $ /`）だけを個別にエスケープし、大文字小文字の指定（`\C` / `\c`）は大文字小文字のある文字を含むときだけ付ける。正規表現は `\v`、単語単位は `\<…\>` で表す。Vim が入力待ち（blocking）のときは入れない。
- Vim のコマンドライン（`/`、`?`、`:`）入力中に IME などで確定した文字は、バッファへは入れず、キーとして Neovim に送る（`<` は `<lt>`）。以前は確定文字が捨てられ、`/日本語` が空のパターンで検索されて「Pattern not found」になっていた。
- 検索バーの「n / 全件」は、エディタのカーソルが一致の先頭にあればその番号を示す。Vim の `n` で移動しても追従する。
- Vim の正規表現をネイティブ検索の正規表現として扱う近似は従来どおり。`\d` などの方言差は変換しない。

## 結果・制約

- 検索バーの一致表示はネイティブ検索の結果に基づく。Vim の `ignorecase` / `smartcase` は反映しない。

## 確認方法

- `npx vitest run src/domain/search.test.ts`（`/`・`?` の読み取り、Vim パターンへの変換）。
- Windows のリリースビルドで CDP 経由のキー入力により確認済み：`/ok` 入力中に検索バーが `1 / 1` を表示し一致を強調、`:s/ok/O` で置換欄に `O`、検索バーに `jj` を入れて Vim で `n` を押すとカーソルが次の一致へ移り表示が `2 / 2` になる。
- `npx vitest run src/presentation/editor/CodeMirrorEditor.test.tsx`（Insert 以外で確定した文字はバッファを変えず Vim へ渡る）。
- macOS / Linux の実機、実際の IME での操作は未確認（CDP の文字挿入で確認）。
