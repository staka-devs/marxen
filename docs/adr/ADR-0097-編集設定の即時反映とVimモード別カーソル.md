# ADR-0097: 編集設定の即時反映と Vim モード別カーソル

- 状態: 採用
- 日付: 2026-10-09
- 関連 Issue: #12

## 背景と選択肢

ライブプレビューでも編集位置を見つけられ、利用者が読みやすい文字サイズや行間を選べる必要がある。設定ごとにエディターを作り直す方式は選択位置や IME の処理を失うため採用しない。

## 決定と理由

設定を外観・エディター・Vim・コピー・AI に分ける。テーマ、文字サイズ、行の高さ、折り返し、行番号、編集行の強調は即時反映し、秘密情報を含まない WebView の利用者設定として保持する。不正な保存値は範囲内へ正規化する。保存できない場合は通知し、その起動中の値を維持する。

CodeMirror の Compartment を再設定し、本文と選択位置を維持する。Neovim のモードを反映し、Normal / Visual は矩形、Insert は細い青いカーソル、Replace は下線で表示する。編集行には薄い背景と左側の目印を付ける。GUI のカーソルは実 Neovim の位置更新に追従し、本文の正本にはしない。

## 結果・制約と確認方法

設定はファイルを開く前にも利用できる。vimrc の再適用は既存の明示的な Neovim 再起動経路を使い、Undo 初期化を適用操作の近くに表示する。画像やファイルの内容、資格情報はこの設定ストアへ保存しない。

設定の再読み込み、入力範囲、実エディターへの反映、カーソルの表示を検証する。カーソル表示の変更後にもブラウザと実 Windows WebView の IME 確認を区別して実施する。
