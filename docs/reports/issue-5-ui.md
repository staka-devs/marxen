# UI・Vim 操作・範囲編集の検証

環境: Windows x64、Node 22.23.2、Playwright 1.63.0、同梱 Neovim 0.11.5。

編集画面は細いアクティビティバー、切替式の単一サイドバー、コンパクトなタブ、広い本文、最小限のステータスバーで構成する。書式・表示基準・原文ビュー・AI 設定はメニューやパネルから操作する。本文とサイドバーは独立してスクロールする。

挿入・置換では実 Neovim のユーザーマッピングを優先し、該当しない入力は正確な半開範囲を置換する。モードが不確かなキーは Neovim へ送り、実行時のモードで処理する。連続入力の位置は投影して入力順を保ち、改訂不一致では再同期する。再送は採取した全文との一致を確認できる場合だけ一度行う。

挿入中のマウス選択は維持し、選択や新しい入力が発生した後は古い非同期応答を反映しない。貼り付けイベントの本文・画像を既定挿入より先に取得し、一度だけ範囲編集として送る。キーボード貼り付けはマッピングを優先し、メニュー貼り付けは直接挿入する。通常モードの Ctrl+V は Neovim の矩形選択となる。

AI 提案は隔離コピーと差分レビューを経て承認する。適用・変更なし・失敗・ロールバックを文書ごとに表示し、適用後は正本の snapshot を取得する。相対画像は文書 ID ごとに解決し、文書切替後の古い取得結果を捨てる。
