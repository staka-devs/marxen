## 最終動作

- 編集画面は細い活動バー（探索・検索・ outline・AI・設定）と用途切替の単一側面、圧縮タブ、単一編集面、最小状態バーで構成する。視点は 100dvh 固定で各面が独立にスクロールする。探索面の見出しは一つとし、木の行は基準名・全経路の表示名・圧縮余白とする。原文方式は編集面のみとし、移動基準の説明は設定の操作説明に置く。
- 印字キーは方式によらず一つの経路で同期的につないで待ち行列に入れ、待ち行列内で実際の方式を読む。挿入・置換では対応写像の前方一致を調べ、該当は原文入力、非該当は正確な半開選択範囲の置換とする。それ以外の方式では原文入力として送る。選択報告の後は実際の方式を取り直し、表示基準の方向移動は選択中は原文へ送る。鍵の直列化は修飾の前に名前を正規化し（Ctrl+方向は `<C-Up>` 等）、平台 IME 鍵と合成・未確定・純粋修飾子は方式によらず OS に残す。
- 挿入中の貼付は貼付事象を先に受け、本文と画像バイトを同期的に読み、既定挿入の前に止めて一度だけ送る。キーボード Ctrl+V は明示写像を先に調べ、メニュー貼付は対応写像を模さず直接挿入する。第一編集は選択範囲を置換し、画像は第一書類を選択範囲に置いて後続を直後に連ねる。新しい改訂で却下された範囲は対応確認が取れる場合のみ一度だけ再送し、画像書込は再送しない。通常方式の Ctrl+V は原文の矩形選択として残す。
- 提案は方式付きで作業複写へ取り込み、質問は表示のみとする。承認は文書毎の結果（適用・変更なし・未適用・巻戻し）で示し、変更なしは成功として数え、失敗は誤り・巻戻し誤り・巻戻し済みで数える。適用文書は snapshot を取り直し、部分適用を全部成功に見せない。複写は実行の確定まで保持する。秘密は画面と localStorage に置かない。
- 相対画像は文書 ID に束ねた解決口で Rust 読込へ送り、遅延到着の切替後は捨てる。同一本文・同一名の二文書でも互いのバイトを再利用しない。読覧は文書で鍵付けする。
- 原文画面は再描画差分を適用して保持し、鍵入力は原文へ送る。選択報告の後は実際の方式を取り直し、表示基準の方向移動は選択中は原文へ送って x 方式の対応写像を優先する。マウス選択の起点を保ち、挿入中の選択は挿入のまま残す。
- live は編集面内の部品描画を用い、読覧は共有表示を用いる。 cursor・スクロール・選択は方式切替で維持する。読取専用表示では保存成功や改訂増加を示さない。
