# 言語と地域の表現

Marxen は `en-US` と `ja-JP` を基本ロケールとし、`ja-JP-x-kansai` と `ja-JP-x-tokushima` を選択可能な地域表現として扱う。関西版は大阪の現代的な日常表現を基本とし、阿波版は徳島市・鳴門周辺を基本とする。地域表現は利用者が明示的に選び、OS の日本語設定だけでは自動選択しない。

メニュー、設定、通知、ダイアログ、検索、チャット、アクセシビリティ名をメッセージカタログで管理する。言語を切り替えても文書、選択、未保存の編集、AI の実行を失わない。利用者が書いた文書、AI の回答、ファイル名、コマンド、`.vimrc` の設定名は翻訳しない。日付・数値・複数形は対応する基本言語の規則に従う。

方言の訳文は一文ごとに用法と文脈を確認する。語尾の自動置換は行わない。技術用語や短いメニュー名は地域でも使われる通常の日本語を残し、通知や案内で地域表現を用いる。標準語から意味が変わる語や、強い感情・冗談に聞こえる表現をエラーに使わない。確証がない訳文は `ja-JP` の明確な文を用いる。

阿波弁の基準資料は徳島大学の研究者による自然談話の調査である。徳島市・鳴門を含む地域内にも差があり、告知・疑問などの文脈によって文末詞の意味が変わる。原因・理由の「けん」と逆接の「けんど」も区別する。特定の文末詞を全ての通知へ機械的に付けない。[鳴門市の方言（阿波学会紀要第61号）](https://library.bunmori.tokushima.jp/digital/webkiyou/61/149-160.pdf)

徳島大学の地域紹介も、近畿の表現と似ていて意味が違う語に注意を促している。訳文は単語の似た印象ではなく、その操作の意味を基準に選ぶ。[徳島大学広報誌・徳島の紹介](https://www.tokushima-u.ac.jp/fs/5/2/7/4/1/_/tokushuu135.pdf)

関西版では大阪の活用と用法を確認し、京都・大阪・他地域の言い方を無差別に混ぜない。国立国語研究所の解説は大阪と東京の語彙・否定過去の違いを示しており、一律の語尾変更では扱えない。[国立国語研究所・方言について](https://kotoba.ninjal.ac.jp/qa/yokuaru/qa-232/)

翻訳の検査ではキーの不足、変数の不足、空のメッセージ、未翻訳キーの画面への露出、言語切替による編集状態の破棄を検出する。資料に基づく確認と、地域話者による訳文レビューを区別して記録する。
